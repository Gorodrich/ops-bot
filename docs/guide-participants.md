# OpsBot 参加者向けガイド

このサーバー（3DS半分こするくらい仲良しクラフト）の運営業務を助けるBot「OpsBot」について、参加者のみなさんが使うコマンドと、知っておくと便利な仕組みをまとめました。**上から順に読めば、どのコマンドをいつ使えばよいか分かるようになっています。**

> **表記について**
> - このBotのコマンドは「/」から始まるスラッシュコマンドです（例：`/kaihatsu set`）。Discordの入力欄に `/` を打つと候補が出ます。
> - 設定できる時間・枚数などの数値は運営側で調整できるため、この文書では「既定では〇〇（変わっている場合があります）」と書いています。正確な現在値がわからないときは運営に聞いてください。
> - コマンドの実行結果は、多くの場合「自分にだけ見えるメッセージ」で返ってきます（他の人には見えません）。

---

## 1. OpsBotって何？

運営が行っている手続きのうち、**機械的にできる作業（受付・集計・通知・記録）をBotが代行する**ものです。
承認する・しないといった**判断そのものは、今まで通り人間（運営や参加者みんな）が行います。** Botが勝手に賛否を決めることはありません。

参加者のみなさんがBotを使う場面は、大きく分けて4つです。

| 場面 | 使うコマンド | 対象 |
|---|---|---|
| Discordアカウントとマイクラアカウントを結びつける | `/authorise` `/whoami` | **全員（最初に必ず1回）** |
| 個人開発領（自分の開発範囲）を届け出る・変更する・やめる | `/kaihatsu` | 個人開発領を持っている／これから作る人 |
| 運営から呼びかけられた参加者投票に投票する | ボタンを押すだけ（`/vote` の開始は運営が行う） | 「人民」ロールを持つ人 |
| 海を埋め立てる許可がほしい | `/umetate` | 埋立てをしたい人 |

> 個人開発領を作る予定がなく、投票の呼びかけもないうちは、**やることは「2. アカウントの紐づけ」だけ**です。

## 2. アカウントの紐づけ（`/authorise` / `/whoami`）— まず最初にこれ

Minecraftサーバーのホワイトリスト登録（＝サーバーに入れるようにすること）や、個人開発領の届出には、
**あなたのDiscordアカウントとMinecraftアカウントを結びつける（紐づける）必要があります。** サーバーに参加したら最初に1回だけ行ってください。

### `/authorise mcuser:<Minecraftユーザー名>`

- 自分のMinecraftユーザー名を入力して実行します。「人民」ロールまたは「仮参加者」ロールを持っている人が対象です（サブ垢用のロールだけでは実行できません）。
- 成功すると、Minecraftサーバーのホワイトリストに**自動で追加**されます（反映まで少し時間がかかることがあります）。
- 次の場合は登録できません：存在しないMinecraftユーザー名／すでに他の人が紐づけているアカウント。
- **一度登録した紐づけは自分では変更できません。** 間違えた・変更したいときは運営者に `/modauth` での対応を依頼してください。

### `/whoami`

- 今の自分の紐づけ状況を確認します（自分にだけ表示されます）。「ちゃんと紐づいているか不安」なときに使ってください。

### 補足

- サーバーを一度抜けて再度参加した場合、**以前と同じMinecraftアカウントなら** `/authorise` を実行し直すと元の紐づけが復元されます。
- サーバーの参加者ロールを外れる（脱退等）と、ホワイトリストからも自動的に外れます。個人開発領そのものは自動では削除されない扱いですが、今後変わる可能性があります。

## 3. 個人開発領の届出（`/kaihatsu`）

**個人開発領を持っている人・これから作る人だけが使います。** 個人開発領（令和8年ルール第3号）に関する届出は、すべてこのBotで行います。
※ 先に「2. アカウントの紐づけ」を済ませておく必要があります。

### 用語

- **ゾーン画像**：自分の開発範囲を「1ピクセル＝1ブロック」で塗りつぶした画像。Botはこの画像で面積や他人の範囲との重なりを機械的に判定します。作り方・ファイル名の付け方（`{ゾーン番号2桁}_{プレイヤー名}.png` 形式）は運営の案内に従ってください。
- **宣言型（せんげんがた）モデル**：下記のとおり「毎回、自分の範囲の全体を届け出る」方式のこと。

### いちばん大事な考え方：「毎回、全体を届け出る」

`/kaihatsu set` で送る画像は、**あなたの個人開発領の「現在の全体像」**です。
以前から持っていた範囲でも、**今回の画像に写っていない部分は「削除された」ものとして扱われます。**

> 「今回増やしたい部分だけ」を送る機能ではありません。**必ず、変更後の全体を送ってください。**

| やりたいこと | コマンド |
|---|---|
| 範囲を広げる／形を変える | `/kaihatsu set`（変更後の全体像の画像を送り直す） |
| 全部やめる | `/kaihatsu delete` |
| 一部だけ消す | `/kaihatsu set`（残したい範囲だけを含む全体像を送り直す） |
| 今の登録状況を見る | `/kaihatsu list` |

### `/kaihatsu set`（設定・変更の届出）

1. 画像を**添付ファイル**として送ります（`image1`〜。最大16枚まで添付できますが、実際の運用上限は運営の案内に従ってください）。画像1枚が1ゾーンに対応します。
2. Botが画像を解析し、**面積の計算・他の人の個人開発領との重複チェック・保護区域との重なりチェック**を自動で行います。
3. 問題がなければ**その場で承認**されます（これを「Bot形式審査」と呼びます）。問題があれば理由とともに却下されます。

- **承認から24時間以内は、運営者1人の操作で撤回されることがあります。** 撤回された場合は、撤回した運営者の名前と理由がDMで届き、その後はあらためて手動審査（運営の秘密投票）に回ります。

### `/kaihatsu delete`（削除の届出）

- 自分の個人開発領を**全部**削除します。**削除は元に戻せません。**
- 一部だけ消したい場合は、`delete` ではなく `/kaihatsu set` で「残したい範囲だけの全体画像」を送り直してください。
- 自分以外の人の範囲を消す場合（譲渡など）は、必ず下記の「同時処理グループ」を使ってください（`mcuser` と `group` の両方を指定）。

### `/kaihatsu list`

- 自分の個人開発領の登録状況（面積・座標）を確認できます。詳しい形はDynmap（地図サイト）のオーバーレイ表示で確認してください。

### 代表者による一括申請（複数人分をまとめて届け出る）

イベントなどで、まとめ役（代表者）が複数人分の画像を一度に送ることもできます。

1. 代表者が複数人分の画像を `/kaihatsu set` に添付して送ると、形式要件を満たしていれば**仮承認**になり、対象者本人にBotからDMで確認が届きます。
2. 本人が**72時間以内**にDMのボタンで「この内容で申請する」を押すと**正式承認**になります（届出の時刻は、代表者が送った時刻までさかのぼって扱われます）。
3. 72時間反応がない／「取り下げる」を押した場合は、**その人の分だけ**却下されます（他の人の分には影響しません）。

- 対象者が `/authorise` による紐づけを済ませていないと、そもそも受け付けられません。

### 範囲の譲渡をするとき（同時処理グループ）

**Aさんが自分の範囲（の一部または全部）をBさんに譲る**場合を考えます。これには「Aさんの範囲を減らす（削除）」と「Bさんの範囲を増やす（設定）」の**2つの届出**が必要です。この2つを **`group` オプションでひとまとめにして届け出ます。**

#### なぜ `group` が必要なのか（指定しないと何が起きるか）

`group` を付けずに、AさんとBさんが**別々に**届出を出すと、次の問題が起きます。

- **Bさんが先に `/kaihatsu set` を出すと、必ず却下されます。** その範囲はまだAさんの個人開発領として登録されているので、「他人の範囲との重複」と判定されるためです。
- では**Aさんが先に `/kaihatsu delete` を出す**と、削除はその場で確定し、**元に戻せません。** この直後にBさんの `/kaihatsu set` が――保護区域と重なっていた、面積上限を超えていた、画像に不備があった等の理由で――却下されると、**Aさんの範囲は消えたまま、Bさんは何も得られません。** 譲渡が途中で止まり、やり直すしかなくなります（しかも、空いた範囲を先に別の人に取られる可能性もあります）。

`group` で束ねると、**「全部成立」か「全部不成立（＝誰の範囲も変わらない）」のどちらか**になります。譲渡が中途半端な状態で終わることがありません。

#### 手順

1. AさんとBさんがそれぞれ、届出に**共通の `group`（好きな文字列でよい合言葉。例：`jouto-abc`）**を付けて送ります。
   - 譲渡元Aさん：`/kaihatsu delete group:jouto-abc`（一部だけ譲る場合は、譲渡後に残る範囲の全体画像を `/kaihatsu set ... group:jouto-abc` で送る）
   - 譲渡先Bさん：`/kaihatsu set image1:<譲受後の全体像> group:jouto-abc`
2. この段階では届出は**溜められるだけ**で、まだ審査は始まりません（合言葉が一致する届出を待っている状態）。
3. 代表者が `/kaihatsu group_finalize group:jouto-abc` を実行すると、そこで受付を締め切り、**2つをまとめて審査**します。
   - Botは内部で**先に削除を適用してから設定を審査**します。そのため、Bさんの範囲は「Aさんの範囲が消えた後の地図」に対して重複チェックされ、上記の「先に出すと却下」問題が起きません。
   - **どちらか一方でも要件を満たさなければ、グループ全体が却下**されます（Bさんの設定が保護区域と重なっていたら、Aさんの削除も行われず、元のまま）。

#### 「代表者による一括申請」との違い

|  | 代表者による一括申請 | 同時処理グループ（`group`） |
|---|---|---|
| 目的 | **手間を減らす**：まとめ役が複数人分の申請を代わりに提出する | **連動させる**：関連する複数の届出を「全部成立か全部不成立か」にする |
| 各届出の関係 | **独立**。1人が却下されても他の人はそのまま進む | **一蓮托生**。1つ却下されると全部却下 |
| 主な用途 | イベントで参加者の `set` をまとめて提出 | 範囲の譲渡（`delete`＋`set` の組み合わせ） |
| 本人確認 | 各対象者に72時間の確認DM | 削除対象が他人の場合は同様に本人確認あり |

一言でいうと、**一括申請は「誰かの代わりに出す」、グループは「バラバラに成立させたくない」ときに使います。**

### 却下・重複について

- 他の人の個人開発領と重なっている場合は却下され、通知に**重複した相手のMinecraft名**が示されます。
- 削除は元に戻せないため、確認用の画像には「削除される範囲」が強調表示されます。**送信前によく確認してください。** 誤って消してしまった場合は、あらためて `/kaihatsu set` で届け出し直してください（消えた範囲の復元はされません）。

## 4. 参加者投票（`/vote`）

参加者どうしで決めるべき事項（例：かつて参加者だった人の復帰の可否、ワールドデータの外部利用の可否、ルール改正など）は、参加者投票にかけられます。

### あなたがすること

- **投票の開始・終了は運営者が行います。** 参加者が自分で `/vote start` を実行することはできません。
- 運営が投票を始めると、**投票専用チャンネルにメッセージが投稿されます。** そのメッセージの「賛成／反対／棄権」ボタンを押すだけで投票完了です。
- **秘密投票です。ボタンを押した結果は自分にしか表示されず、誰が何に投票したかは他の人には分かりません。**
- 投票権があるのは「人民」ロールを持つ人です。

### `/vote status`

- 進行中の参加者投票の状況を確認できます。投票IDを指定すると個別の投票、省略すると一覧が表示されます（入力中に件名で候補が出ます）。

### 締切について

- 締切は開始から既定24時間後です（設定で変わることがあります）。
- 締切の集計は定期実行（10分おき）のため、締切ちょうどではなく**数分〜最大10分ほど遅れて**結果が投稿されることがあります。これは不具合ではなく仕様です。
- 全員の投票が早く出そろった場合など、運営者が `/vote end` で締切前に集計することもあります。

## 5. 海の埋立ての許可（`/umetate`）

海を埋め立てたい人が、許可を要請するために使います（禁止事項及び罰則に関するルール第11条第1項）。

### `/umetate`

- `image`（範囲を示す地図画像）または `description`（文章での説明）の**どちらか一方は必ず指定**してください（両方でも可）。
- 実行すると運営専用チャンネルに要請が投稿され、「運営」ロールを持つ人**2人以上**が「OK」ボタンを押すと**成立**します。成立すると申請者にDMで通知が届きます。
- 誰がOKを押したかは**記名式で公開・記録**されます（4章の秘密投票とは別の仕組みです）。

## 6. よくある質問

**Q. サーバーに入ったばかりです。まず何をすればいいですか？**
A. `/authorise mcuser:<自分のMinecraftユーザー名>` を1回実行してください。これでホワイトリストに登録され、サーバーに入れるようになります。

**Q. 個人開発領を少しだけ広げたいのですが、変更したい部分の画像だけ送ればいいですか？**
A. いいえ。`/kaihatsu set` は常に「現在の全体」を表します。変更後の全体像を送ってください。写っていない部分は削除扱いになります。

**Q. 誤って個人開発領を削除してしまいました。元に戻せますか？**
A. 戻せません。あらためて `/kaihatsu set` で届け出し直してください。

**Q. アカウントの紐づけを間違えました。自分で直せますか？**
A. 自分では変更できません。運営者に `/modauth` での修正を依頼してください。

**Q. 投票で自分が何に投票したか、他の人にバレますか？**
A. バレません。ボタン操作への応答は本人にしか表示されません。

**Q. 締切時刻ちょうどに投票が締め切られないのはなぜですか？**
A. 締切処理が定期実行（10分おき）のため、最大10分ほど遅れることがあります。仕様どおりの動作です。

**Q. コマンドを実行したのに、他の人に返信が見えていないようです。**
A. Botの返信は多くの場合「自分にだけ見えるメッセージ」で返ります。正常です。
